# 월간 배터리 논문 뉴스레터 → 카카오톡 자동 발송 PLAN

> 한 줄 요약: **매달 한 번, Claude가 "논문 큐레이터"로 출근해서 화제작을 고르고 그림 중심 요약 페이지를 만든 뒤, "우체부(카카오 API)"가 내 카톡으로 링크 카드를 배달한다.**

---

## 0. 전체 구조 (비유로 보기)

```
[① 알람시계]        [② 큐레이터]          [③ 인쇄소]          [④ 우체부]
 매월 정해진 날  →  논문 찾기·선별·요약  →  웹페이지 뉴스레터  →  카카오톡 "나에게 보내기"
 (예약 작업)        (Claude)               (Artifact 페이지)     (카카오 REST API)
```

- **카톡 메시지 자체에는 긴 글·여러 그림을 못 담는다.** 카톡은 "봉투"(제목 + 썸네일 1장 + 버튼) 역할만 하고, **본문(그림 + 요약)은 웹페이지**에 둔다. 카톡 카드를 누르면 페이지가 열리는 방식.

## 2. "화제작/필독" 고르는 기준

클릭수(다운로드 수)는 저널이 공개 API로 주지 않는 경우가 많다. 그래서 **대체 지표 3가지**를 섞는다.

1. **극장 급** – 어느 저널에 실렸나 (Nature/Science 계열, Joule, EES, AM/AEM, ACS Energy Lett. 등)
2. **입소문** – Altmetric 점수(언론·SNS 언급), 보도 기사 여부(TechXplore 등)
3. **흥행 초기 성적** – 인용 수(OpenAlex/Crossref), 단 1개월 된 논문은 인용이 거의 없으므로 보조 지표

→ 분야별 **화제작 1~2편 + 필독 1~2편**, 총 6~8편 목표.

---

## 3. "Figure 중심 요약"과 저작권 ⚠️

논문 그림은 저작물이라 **함부로 복사해서 재배포하면 안 된다.**

| 논문 유형 | 처리 방식 |
|---|---|
| 오픈 액세스 (CC-BY, 예: Nature Communications OA) | 그림 사용 가능 → **출처·라이선스 표기** 후 삽입 |
| 구독 논문 (paywall) | 그림 복사 ✗ → **"Fig. 2를 보세요" + 해당 그림 링크 + 그림이 보여주는 내용을 글로 요약**, 필요시 Claude가 개념도를 새로 그림 |

→ 뉴스레터는 개인 열람용이지만, 링크가 공유될 수 있으니 이 원칙을 기본값으로 둔다.

### STEP 1. 카카오 "우체부" 준비 — ✅ 완료 (2026-10-22, 테스트 메시지 수신 확인)
> 실제 설정 메모: Redirect URI = `https://example.com/oauth` (localhost는 동작 안 함), 클라이언트 시크릿(카카오 로그인용) **ON** → 토큰 요청 시 `client_secret` 필수

2. 카카오 로그인 활성화 + Redirect URI 등록

4. 최초 1회 로그인 → **액세스 토큰 + 리프레시 토큰** 발급
5. 테스트 메시지 1통 보내서 카톡 도착 확인 ✅

> 🔑 열쇠 비유: 액세스 토큰 = **6시간짜리 임시 출입증**, 리프레시 토큰 = **60일짜리 출입증 재발급권**.
